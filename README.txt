DEVCLUB • MEU PAINEL PWA

Arquivos:
- index.html
- style.css
- java.js
- manifest.json
- sw.js
- icons/

Recursos:
- Dashboard estilo painel/ticket
- Tickets de dúvidas
- Anotações por categoria
- Upload de fotos/prints
- Progresso do curso
- Tema claro/escuro
- Dados salvos no localStorage do navegador
- PWA instalável

COMO TESTAR:
1. Coloque a pasta em um servidor local.
2. Abra pelo Chrome em http://localhost/... ou use VS Code + Live Server.
3. Para instalar como PWA em produção, publique em HTTPS.
4. O botão "Instalar aplicativo" aparece quando o navegador reconhecer os requisitos do PWA.

OBSERVAÇÃO:
As fotos são salvas no armazenamento do navegador usando localStorage. Para muitas fotos, a próxima evolução recomendada é migrar fotos e dados para IndexedDB.
